#🗳️ Blind Voting System

An accessible voting system for visually impaired voters using Speech Recognition & Text-to-Speech.

This project enables blind and low-vision citizens to vote independently, privately, and securely — without needing help from others.

## ✨ Features
- 🔊 Voice-guided voting with Text-to-Speech (TTS)
- 🎙️ Voice input using Speech Recognition
- 🪪 Aadhaar-based voter verification
- 🗳️ Audio confirmation of selected candidate & party symbol
- 🔒 Secure vote storage in MySQL database
- 👨‍💼 Admin dashboard to manage candidates, parties & results
- ♿ Fully accessible - No screen needed to vote

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP, Python
- **Database:** MySQL
- **Voice:** Speech Recognition API, Text-to-Speech (pyttsx3 / Web Speech API)

## 🚀 How To Run
1. Clone the repo:
   git clone https://github.com/thrishalshett/Blind_Voting_System.git
2. Import the database file into MySQL (phpMyAdmin)
3. Start XAMPP / Apache & MySQL
4. Open in browser:
   http://localhost/Blind_Voting_System

## 🎯 Problem Solved
Millions of visually impaired voters in India struggle to vote independently and often need assistance, which compromises their privacy. This system gives them a fully independent voting experience.
